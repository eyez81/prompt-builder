# בונה הפרומפטים

אפליקציה סטטית ורספונסיבית לבניית פרומפטים בעברית. אינה דורשת שרת, מסד נתונים או מפתח API.

## הפעלה מקומית

פתחו את `index.html` בדפדפן.

## העלאה ל-GitHub Pages

1. צרו מאגר חדש ב-GitHub.
2. העלו אליו את כל הקבצים והתיקיות שבחבילה — לא את קובץ ה-ZIP עצמו.
3. היכנסו ל-`Settings` ואז `Pages`.
4. תחת `Build and deployment` בחרו `Deploy from a branch`.
5. בחרו בענף `main`, בתיקייה `/ (root)` ולחצו `Save`.

## מבנה הקוד

- `index.html` — מבנה האפליקציה והתוכן.
- `styles.css` — העיצוב וההתאמה למסכים שונים.
- `app.js` — התבניות, בניית הפרומפט, מד האיכות והשמירה המקומית.
- `fonts/Heebo-Variable.ttf` — גופן Heebo מקומי.

התבניות נמצאות בתחילת `app.js` במערך `templates`, ולכן קל לשנות או להוסיף תבניות בעתיד.
